# 火焰格同步口径

火焰不是独立的“爆炸事件”数据，而是**世界地形状态**：

- 主机 `SubsystemFireBlockBehavior` 维护火焰表并调用 `SetCellOnFire` / `ChangeCell`；
- `SuSubsystemFireBlockBehavior` 在主机侧捕获火格写入，走既有地形 CellChange 同步；
- 客户端副本只接收主机下发的火格内容，**不本地推进火焰、不写火焰表、不产生新火格**；
- 因此客户端看到的火焰、烧尽和地形变化来自地图/区块同步，不需要另建爆炸火焰消息。

## 结论

- 火药桶、燃烧弹、火焰蔓延的最终火格由主机权威地形同步到达客户端；
- 联机层不再额外执行“炸弹爆炸后补燃”的火格延伸；
- 炸弹投掷时的点燃/火花尾迹属于投射物表现，由客户端投射物复制层单独处理，不写地形。
