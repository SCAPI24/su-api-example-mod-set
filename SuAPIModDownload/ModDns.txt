# 这是联机模块的**重写版**：模块化架构（Session/Terrain/Circuit/Player/... 各自独立），
# 与旧 ScMultiplayer 的协议、存档格式、服务发现都不同，两者**不能混用**。
#
# 2.3.1（2026-11-08）：在 2.3.0 基础上补齐无头服务器运维与角色管理：
#   · 跨 Mod 控制通道：`SuMultiplayer.Control` 事件（与 `ScMultiplayer.ServerSettings` 那种
#     "用不存在的事件名" 的做法彻底分开）。无头服务器控制台据此读写设置，两边不引用程序集。
#   · 房间容量 MaxPlayers：语义是**对外连接数**（一台设备算一个连接，与它上面几个本机角色无关）；
#     0 = 关闭加入。改完立即生效（房间信标下次应答即读新值），不用重开房。
#   · 日志模式三档：Runtime / Only Self（只有主机落盘）/ All Players（主机+客户端都落盘）。
#     Only Self 让主机能自己留档复盘，又不会把客户端磁盘写满。
#   · 聊天历史：HUD 的 8 秒窗口之外另存 200 条（纯内存、不落盘、重连同清），
#     供无头服务器控制台的聊天室回看。
#   · 联机角色管理：控制台可列出/改名/改皮肤/改数值/删除 **SuMultiplayerPlayers.xml** 里的
#     角色记录（离线角色也能删，由主机端保存）。数值改动只对在线角色立即下发。
#   · 主机角色"幽灵身体"：无头服务器的主机没人操作，那个本机角色会永久站在世界里。
#     幽灵化 = 摘掉碰撞/渲染/更新（别人看不到、打不到、他也打不到别人）+ 置为睡眠
#     （否则客户端全睡时世界永远不会加速），PlayerData/背包/坐标全部保留，随时可复原。
#     只针对主机自己的角色。
# 2.3.0（2026-11-08）：本版是重写版第一次对外发布，包含自 0.1.0 起的全部功能与修复：
#   · 端口模型：10 个房间槽位，每槽 TCP+UDP 同端口；发现走 UDP；`suceru.site:3103` 单端口、
#     `suceru.site:3103-10` 表示 3103 起的 10 个端口范围。
#   · 日志分层：上线模式默认**只进内存不写盘**（缓冲满即丢弃），主机可在联机设置界面
#     或 `verbose true/false` 运行时切成 Debug 落盘并下发所有客户端（不关房、不改配置）。
#   · 电路同步：主机权威；客户端每帧按地形同样的就绪判据；地刺板/灯/圣诞树灯的输出状态
#     改由主机地形同步下发（客户端不再自己求解这些一次性信号）。
#   · 重连：主机正常退出会主动通知客户端立即退出；主机强杀时客户端保持世界 30 秒重连窗口，
#     窗口内仍按副本模式（世界模拟保持停止，避免离线改乱世界）。
#   · 可编辑方块（内存条/真值表）：乐观锁 + 主机权威，被拒会明确回滚。
#   · 角色记录 SuMultiplayerPlayers.xml：世界导出前保存，落盘失败只在**真失败**时告警。
